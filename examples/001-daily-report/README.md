## 口径决定结果

只纳入2026-10-31、已支付、未退款、关键字段完整且无同ID冲突的唯一订单。规范后的日期、金额、状态及币种全部相同才合并；完整来源保留。同ID内容冲突时整单待确认，不猜最新一条、不取平均。金额以整数分累计。

原始30行的互斥去向：纳入15行、完全重复多余5行、待确认4行、退款3行、待支付2行、非报表日1行。退款3笔350元单列；已经排除在主金额之外，不再扣一次。`clean.csv`含21笔规范唯一订单，包括主指标之外的状态，不是仅含15笔。

OD-001金额100元，在A表第2行与B表第2行各出现一次；规范内容相同，只计一次，两处来源均保留。OD-009在两份快照分别为500元与550元，两行均待确认。

原始金额直接相加的6,582.70元是有意设置的错误口径对照，不是实际Agent失败记录。本期金额是订单快照指标，不是财务收入或税务结论。

## 在自己的电脑复现

Python 3.10以上。以下命令在解压后的本目录执行；已有Excel和Word可直接打开，无需安装任何生成工具。

```bash
# 从实际提供的3份XLSX读取数据，输出到新目录，保留原交付不动
python3 case/run_case.py --xlsx-dir case --out rerun

# 从新导出的原始CSV另行核算，不调用生产分析逻辑
python3 document/validate_independently.py --case rerun --out rerun/independent-validation.json

# 只有重新生成Word时才需要此依赖
python3 -m pip install -r requirements.txt
python3 document/generate_report.py --truth rerun/truth.json --out rerun/report.docx --facts-out rerun/report_facts.json
```

计算、XLSX读取及独立核算只用Python标准库；Word需要python-docx。Word构建器排版已核对的truth，不负责分析新数据。跨平台字体替换可能改变分页，重新生成后应检查版式。

本例字段、日期格式与读取范围有固定约定：首工作表A1:E11、三份输入共30行、示例订单ID和日期，以及内置的案例变更检查。它是固定合成案例的复现包，不是任意Excel的通用识别产品。处理新的真实业务表时，先确认映射、范围、日期和状态口径，调整分析与独立验收，不沿用本例数值。
